# Посмотри в окно

Учебный проект Яндекс Практикума. Приложение показывает видео с видами из окон разных городов. Ролики можно искать по городу и времени суток, а затем выбирать в списке.

## Запуск

Клонируйте репозиторий и откройте `index.html` в браузере. Для загрузки видео требуется интернет.

[Репозиторий проекта](https://github.com/MakRo123123/posmotri-v-okno-ad)
